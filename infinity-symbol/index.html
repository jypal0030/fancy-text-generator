Which infinity character should I use?

Use ∞ (U+221E) for standard mathematical notation, such as x → ∞. The emoji ♾️ can appear in colour, but it is a different character sequence. If the editor uses LaTeX, use \infty in maths mode instead of pasting the emoji.

The less common variants may show up as empty boxes on devices without a supporting font.
