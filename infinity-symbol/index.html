Which infinity character should I use?

For maths, copy and paste ∞ (U+221E), as in x → ∞ or the interval [0, ∞). For a message or bio, use ♾️ (U+267E followed by U+FE0F), which can appear in colour depending on the app. If you’re writing a LaTeX equation, type \infty in maths mode instead.

For a decorative caption, try Always ♾️. For a plain-text divider, try ∞ Notes ∞. The less common variants may show up as empty boxes on devices without a supporting font.
