Outline hearts, filled hearts and emoji

Try ♡ for a light caption accent, ♥ for a filled heart in plain text, or ❤️ when you want an emoji. For example, use Art ♥ Music as a short bio divider.

❤︎ requests text styling, while ❤️ requests emoji styling. Some apps ignore that distinction, so check the heart after pasting. For a plain outline, try ♡, as in Made with care ♡.
