Is this a font you install?

No. The generator replaces A–Z letters with Unicode script characters. Numbers, punctuation and accented letters stay as typed. Whether the script displays correctly depends on the app and device where you paste it.

  • Regular script: Love → ℒℴ𝓋ℯ for a short sign-off.
  • Bold script: Love → 𝓛𝓸𝓿𝓮 to emphasize a single word.

Use script for a short flourish rather than an entire message. Screen readers may not pronounce these characters like ordinary letters. For angular blackletter instead of flowing script, try the Gothic Font Generator.
