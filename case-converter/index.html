Which conversion should I use?

Use title case for headings such as “A Guide to Text Styles.” For code, follow your project's convention: order_total is snake case, ORDER_TOTAL is screaming snake case, and orderTotal is camel case.

HTTP header case produces names such as Content-Type; it formats text without validating whether the header exists. For web paths, URL slug mode produces results like summer-sale. It strips accents from Latin letters and removes characters outside ASCII letters and numbers rather than transliterating other writing systems.

Case converter examples

  • Snake case: Order Total → order_total for a name such as a database column.
  • Screaming snake case: Max Retry Count → MAX_RETRY_COUNT for a constant.
  • HTTP header case: content type → Content-Type.
