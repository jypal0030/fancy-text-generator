Using maths symbols in plain text

Write simple expressions like π ≈ 3.14 or √9 = 3 without an equation editor. These characters are useful for display, but calculators, spreadsheets and code editors may require their own syntax, such as * for multiplication.

Use × as the multiplication operator in 3 × 4 = 12, and use the ordinary letter x as a variable in x ≤ 4. The two characters look similar but mean different things.
