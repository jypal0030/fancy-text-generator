Flower text symbols or flower emoji?

Try ❀ Garden notes ❀ for a heading, ✿ · ✿ · ✿ for a divider, or 🌷 Spring sketches for a bio. Text ornaments like ❀ usually take the colour of the surrounding text, while emoji like 🌷 use artwork that varies by app or device.

If a symbol shows up as a box, try a different ornament or emoji and check the result in the app where you’ll use it.
