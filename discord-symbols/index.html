Where can you paste Discord symbols?

  • Display name: ✦ Nova uses a star as an accent.
  • Bio: Games │ Art separates two interests with a divider.
  • Message: ↳ Read the rules uses an arrow to draw attention to an instruction.

Keep the words readable so the symbol isn’t the only cue.

Display names and account usernames have different rules. A symbol that works in a message may be rejected in a username or channel name, so check it in the target field. These are Unicode characters, not custom server emoji.

For more options, browse all symbol collections or try Kaomoji and Japanese Emoticons for text reactions.
