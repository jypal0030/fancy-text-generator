Which cross symbol should I use?

Use ✝ for the Latin cross. For a plain ornament without the extended lower arm, try ✚. The dagger † looks similar to a Latin cross but is commonly used for footnotes.

For arithmetic, choose ×, as in 3 × 4 = 12. For an incorrect answer, try ✖ or ❌. For a plain-text letter, use x instead. Browse maths symbols for division, square roots and inequality signs.

If you need a cross that looks like plain text, try ✝︎; it requests text presentation. ✝️ requests emoji presentation. Your app may ignore that request, so check the symbol after pasting.

Cross symbol FAQ

How do I copy and paste a cross symbol?

Select Copy below the cross you want, then paste it into the destination field. If automatic copying fails, select the character and use your device’s copy command.

Can I paste a cross into Instagram, Discord, or WhatsApp?

Try it in an Instagram bio, a Discord message, or a WhatsApp chat. Check the result before posting: the same character can look different across apps, and account usernames may have stricter character rules than bios or messages.

Are ✖, ×, and x the same character?

No. ✖ is an X mark (U+2716), × is the multiplication sign (U+00D7), and x is the lowercase letter (U+0078). Use the sign for arithmetic and the letter for a variable, as in 2 × x = 8.
