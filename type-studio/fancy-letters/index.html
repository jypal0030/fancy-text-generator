Are these installable fonts?

No. These are Unicode characters that look like styled letters. Some apps and screen readers handle them differently from ordinary letters. Check the result after pasting, and keep important information in plain text.

To style an entire word or phrase instead of a single letter, use the Fancy Text Generator.
